// 02 — about

From help-desk and support to a self-built server rack.

A snapshot of how I work and what I work with.

I started in IT support solving day-to-day problems for real users — Windows updates, hardware faults, antivirus, backups — the unglamorous work that keeps an office running. That grounding taught me to diagnose calmly and document clearly, skills I still lean on.

Over time the work moved from hardware and OS issues toward application, database, and API problems — reading logs instead of guessing, tracing a bad query or a failed request back to what actually caused it.

On my own time, I run a Proxmox VE homelab: virtual machines, LXC containers, Docker workloads, and a small pile of self-hosted services, all reachable through a secured Cloudflare Tunnel. It's where I test the infrastructure ideas that a help-desk ticket doesn't leave room for.

I'm now an AWS Certified Cloud Practitioner, and I'm looking to move that hands-on foundation into a Cloud Support, Systems Administration, or IT Infrastructure role — somewhere I can support production systems and keep learning the cloud side properly.
